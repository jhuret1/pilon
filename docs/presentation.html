Status / v0.3.0a1 local alpha

A working baseline, clear boundaries

Implemented baseline

  • Discovery and a persistent local loop
  • Lexical extraction and source checks
  • Local export watcher and reports
  • Projections, publication, and rollback

Reusable interfaces

  • CSV, JSONL, and Python feeds
  • Custom extractor callbacks
  • Optional supplied vectors
  • Evidence and model-diff contracts

Roadmap / evaluation

  • Production source connectors
  • Live storefront and index integration
  • Richer document and image adapters
  • Measured ANN / TDA comparisons

Publication changes local snapshots. External systems need your own integration. TDA and ANN are not deployed defaults. Source checks do not establish AI accuracy.
