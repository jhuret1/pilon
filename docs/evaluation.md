# How to evaluate induction

The shipped fixture set has predetermined outputs. Its successful replay measures
software integrity, **not extraction quality or ontology quality**. Amazon supplies
real text but no gold fact labels. Downloading 20 reviews is a smoke test, not a
representative evaluation.

For an independent experiment:

1. Freeze a dataset revision and split by product, grouping identical texts together.
2. Keep test products out of prompt examples, ontology development and threshold tuning.
3. Label assertions with exact spans, predicate identity, values, subject and time.
4. Label equivalent, parent/child, distinct and ambiguous concept pairs, including
   difficult negatives. Label reviewers must not see system suggestions initially.
5. Compare extraction recall, predicate precision, value accuracy and evidence
   sufficiency separately. An exact substring is not sufficient evidence by itself.
6. Measure duplicate concepts, invalid merges, missing concepts, family assignment,
   and unassigned/assertion rates. Lower concept count alone is not improvement.
7. Repeat ingestion in several recorded orders; compare identity and hierarchy stability.
8. Report sample sizes, language distributions, model versions, disagreement policy,
   confidence intervals, wall time, provider calls, actual costs and unconfirmed costs.

If labels are generated by another LLM, report model agreement and audit a blind
subset; do not call the labels human ground truth. Split training, calibration and
test at the product level. Set thresholds on calibration only. Include absence,
failure, repairs, comparisons, unknown subjects, multilingual text and no mention.

Candidate routing can save arbitration calls through exact identity reuse. It does
**not** currently avoid the extractor's LLM call per review. Report each stage's
calls instead of claiming a global LLM saving from the routing percentage alone.

The local viewer leaves precision and recall unmeasured until a genuine labeled
evaluation exists. Model confidence is not calibrated factual probability.
